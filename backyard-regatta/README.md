# Puddle Cup

A 90-second toy sailboat race through a flooded backyard. Built with Three.js, TypeScript, and Vite.

## Play

- `A` / `D` or arrow keys steer.
- `W` trims the sail tight.
- `S` eases the sail out.
- `Esc` pauses.
- Hold `R` to restart.

## Develop

```sh
npm install
npm run dev
```

Run the checks with `npm test` and `npm run build`.

## Deploy

The app uses Cloudflare Workers Static Assets.

```sh
npm run deploy
```
